# 概念構成とデータの進行

## この文書の位置づけ

本書は、[SPEC の構成と Interface](../SPEC.md#構成と-interface)で選択された構成を、責務・所有・時間・失敗の関係から説明する補助文書である。製品要件と継続条件の唯一の正本は [SPEC.md](../SPEC.md) であり、本書から新しい仕様を決めない。数値、初期値、依存の改訂は正本の該当節を参照する。

文書整備時点では未実装・実機未検証である。以下は稼働中の構成や性能の実測結果ではなく、選択済み設計の説明である。具体的な型、呼び出し形式、細かなファイル配置、実装順序は定めない。最終承認と次の作業への条件は [文書の状態](../SPEC.md#文書の状態)と[仕様の管理と次に進む条件](../SPEC.md#仕様の管理と次に進む条件)に従う。

関連文書は [索引](README.md)、[検証手順](verification.md)、[参考資料](references.md) を参照する。

## Module の責務と所有

Interface は渡す値だけでなく、その意味、更新の扱い、失敗時の継続条件を含む。Implementation はその規則を内部に閉じる。Module の分担は次のように読む。

| Module | 入力と出力の意味 | 所有する状態・資源と内部に閉じる責務 |
|---|---|---|
| シチュエーション登録 | 他の Module に、安定した識別子、ノブ仕様、声の準備方法、見え方を提供する | 環境固有の合成とパラメータ曲線。登録順と表示名を、自動移動の順序や保存識別子と混同しない |
| 音声と世界 | 最新の設定・指示を受け、音声、時刻付き視覚イベント、世界の状態を出す | 世界時計、揺らぎ、粒の発生、声の実行状態、混合ゲイン、滞在・交差・途中選択。実行中の声を UI が直接変更しない |
| シーンと設定 | 世界とイベントを読み、操作を渡す | 表示中の粒、現在の viewport、フォームの入力状態、外観。窓サイズは表示の状態であり、音の世界の寸法ではない |
| 状態保存 | 保存対象の設定を読み書きし、完了または失敗を返す | 保存形式の解釈、既定値・範囲の調整、未知の値の保持、退避、一時ファイルからの置き換え。瞬間的な世界を保存設定として扱わない |
| macOS と更新 | OS の状態とユーザー操作を、既存の Module に渡す | アクセシビリティ、窓制約、更新画面、終了・再起動の調整。OS の都合を音声や保存の規則へ無制限に持ち込まない |

根拠は [構成と Interface](../SPEC.md#構成と-interface)と[シチュエーション](../SPEC.md#シチュエーション)。登録を使う側は、個別のシチュエーション名で混合・表示・保存の処理を分岐させない。環境固有の変更と、混合・保存・窓・更新の変更理由を分けている。

GPUI がアプリの実行ループを持ち、シーンと設定はその上の別窓となる。AppKit の窓制約や Sparkle の操作に必要な Adapter は、OS と既存の Module をつなぐ範囲に限定する。設定窓や更新のために別のアプリホストへ置き換える構成ではない。

## 操作から音と絵まで

| 進行 | 渡すものと解釈 |
|---|---|
| メニュー・設定 → 音声と世界 | 最新の選択、整合したノブの組、消音・音量・移動設定。古い選択の順番待ちではなく、現在の世界へ適用する指示 |
| 音声と世界 → 出力 | 寄与する声を合成・混合し、移動ゲインとは別に全体音量と消音を適用した音声 |
| 音声と世界 → 視覚イベント | 同じ粒から決めた時刻、所属、正規化位置、強さ、大きさ、形、寿命。音の左右位置と絵の左右位置は同じ根拠を使う |
| 時刻付きイベント・世界 → シーン | 出力の再生予定時刻に対応づけた世界と、現在も生きている粒。現在の viewport に配置する |
| 設定・窓状態 → 保存 | 保存対象の設定と落ち着いた矩形。完了または失敗を UI と終了・更新の判断へ返す |

音声描画が世界時計を進める。描画側で独立した粒を乱数生成したり、FFT から別の世界を推測したりしない。世界の粒・息・天候と、ノブの意味を音声側に閉じるため、窓を変えても音の規則は変わらない。

視覚イベントは容量固定のリングバッファで渡す。表示側も固定容量で扱い、容量超過では古い・弱い視覚イベントを省く。これは音声を待たせたり、音の粒を省いたりする理由ではない。シーンを再表示するときも、隠れていた間の粒をまとめて光らせず、生存中のイベントだけを扱う。詳細は [音と絵](../SPEC.md#音と絵)と[視覚イベント](../SPEC.md#視覚イベント)を参照する。

## 実行場所と準備の関係

[スレッドと資源](../SPEC.md#スレッドと資源)では、処理の責任とリアルタイム経路を分けている。

- **オーディオコールバック**は、準備済みの声のうち寄与する声のサンプル列を生成し、混合と世界更新を行う。消音や音量がゼロでも必要な世界更新は続け、出力に不要なサンプル生成は省ける構成とする。
- **GPUI／AppKit メイン**は、窓・操作・外観・OS 連携・更新画面を扱う。オーディオの実行状態を直接編集せず、最新の設定と指示を渡す。
- **保存処理**は、変更が落ち着いた時点と終了前に保存する。オーディオから呼ばず、更新時には保存完了を判断に使う。この分担は保存専用スレッドの具体構成を決めるものではない。

声の構築・資源の破棄、サンプルレートの準備、内部バッファの確保はコールバック外で行う。登録に応じた声と、粒・制御・イベントの容量を準備してからリアルタイム経路で使う。コールバック内でサンプル列を生成することと、声を構築することは別である。寄与しなくなった声のサンプル生成を止めることと、声の資源をコールバック内で破棄することも区別する。

コールバック内には確保・解放、ロック待ち、ファイル I/O、ネットワーク、UI 呼び出しを入れない。制御の受け渡しは容量が定まったロックフリーの方式という既存の条件に従うが、本書は具体的な方式や容量を追加しない。最新選択の優先、消音・音量・移動設定の独立、ノブの組の整合を Interface の意味として保つ。ライブラリ名や汎用グラフの機能だけでは、この経路のリアルタイム性は証明されない。

## 滞在・交差・連続選択

滞在中は到着した環境が寄与し、自動移動が有効なら次の移動を待つ。自動交差では出発側と到着側の寄与を変える。登録順の巡回ではなく、登録に基づく選択である。抽選、操作による自動移動の切り替え、時間設定の適用時点は [体験](../SPEC.md#体験)と[時間設定](../SPEC.md#時間設定)に従う。

手動選択や環境ノブの編集は、現在の混合から対象へ寄せる。交差の途中で別の環境が選ばれても、いったん片側へまとめてから新しい声を入れるのではない。新しい選択を受け取った次の音声描画区間から、その時点のゲインを出発点として切り替え直す。

連続選択は最新の選択が優先される。既に寄与している声への選択でも現在の混合からその声へ寄せ、既にその声だけなら不要な交差を始めない。ゲインを不連続にせず、無音を挟まず、声の重なりによる意図しない増音を避ける。完了後は選択先だけが寄与する。交差時間や声の準備条件は [切り替えと途中操作](../SPEC.md#切り替えと途中操作)を参照する。

移動をオフにする操作は、進行中の交差を途中で打ち切る操作ではない。共通の音量・時間設定の変更も、環境の選択とは意味が異なる。時間設定の変更は進行中の待ち時間・交差を作り直さず、正本で定めた次の適用時点に使う。

## 無音・非表示・世界停止の違い

以下は実装の動作報告ではなく、[消音・スリープ・出力停止](../SPEC.md#消音スリープ出力停止)の状態を、責務の違いとして整理したもの。

| 状態 | 進むもの／止まるもの | 再開時の意味 |
|---|---|---|
| 消音・音量ゼロ | 出力は無音でも世界・滞在・交差は進み、絵は同じ世界に従う | 音量や消音の変更は世界の再初期化ではない |
| シーン閉鎖・最小化・完全な非表示 | 音と世界は続き、シーンのアニメーションだけ止める | 現在の世界を描く。非表示期間の視覚イベントを一括再生しない |
| スリープ | 世界・滞在・交差と出力・描画を止める | 直前の論理状態と残り時間から再開し、経過した睡眠時間を一括反映しない |
| 出力使用不能 | 世界時計と出力を止め、シーンは最後の状態を静止する。窓と操作は維持する | 標準出力の復旧で自動再開し、音を滑らかに戻す。ユーザーの消音設定は解除しない |

出力変更時の準備はオーディオスレッド外で行い、論理状態を維持する。これは DSP 内部位相や残響まで機器切り替え前後で完全に一致させる保証ではない。復旧先がスピーカーになることも、単なる描画再開とは異なる音声上の意味を持つ。

## 時刻の基準と対応づけ

世界の生成時刻、出力先でサンプルが再生される予定時刻、描画の単調時計は同じ意味ではない。イベントの生成時刻だけで光らせると、生成後の出力遅延を扱えない。

[再生予定時刻](../SPEC.md#再生予定時刻)に従い、CPAL の出力コールバック情報とサンプル内の位置から再生予定時刻を扱い、DSP の遅延を含めて描画の単調時計へ対応づける。描画はこの補正時刻に対応する世界と粒を読む。

出力再初期化、サンプルレート変更、スリープ復帰では対応を張り直す。古い対応のイベントを新しい出力へ持ち越して再生しない。論理状態の保持と、出力・描画時計の対応の保持は別である。

再生予定時刻自体も推定値であり、この設計だけで物理的な音と光の同時性を保証しない。自動補正の範囲、出力機器ごとの検証条件と残る制約は正本を参照する。

## viewport と窓の寸法

viewport は、そのフレームで粒を配置する表示領域である。世界は正規化位置を持ち、描画時に最新の領域へ写す。リサイズは世界の粒・乱数・天候・移動・声を作り直す理由にならず、音声の処理量も面積比例で増やさない。

寸法は次の役割を区別する。

| 寸法 | 扱う場所と意味 |
|---|---|
| 正規化位置 | 世界の粒の位置。viewport の大きさから独立する |
| 論理コンテンツ寸法 | シーンの配置、光の半径・余白、設定フォーム、最小サイズ。幅と高さの別々の拡大で円を変形させない |
| 外枠寸法・位置 | ディスプレイの作業領域と窓復元。コンテンツ寸法への変換を明示する |
| 物理描画寸法 | 論理寸法と現在の倍率から決まる描画面。GPU の許容範囲と確保・合成コストに関わる |

表示領域の更新は最新値を使い、古い寸法の配置を後から適用しない。過渡的に空の領域になった場合は描画を休み、音を止めない。ディスプレイ移動による倍率変更と論理サイズの変更も別々に扱う。詳細と下限は [サイズ変更への耐性](../SPEC.md#サイズ変更への耐性)を参照する。

通常窓の上限は所属ディスプレイの現在の作業領域を基準にし、外枠からコンテンツへ変換する。その画面上限と、物理描画寸法から戻した描画側の上限の小さい方を使う。画面・倍率・復帰状態が変わったら取得し直し、ディスプレイを一時的に取得できないことを無制限なサイズの理由にしない。フルスクリーンと OS の最大化は同一の操作として扱わない。

窓制約の Adapter はメインスレッドに閉じ、GPUI の窓 delegate を置き換えない。コンテンツ上限の設定だけで復元やフルスクリーン復帰を含む全経路が安全になるとはしない。描画面を確保した後に縮めるだけでは、過大な確保の予防にならない。根拠は [最大サイズと描画負荷](../SPEC.md#最大サイズと描画負荷)と[基盤のサイズ制約と既知のコスト](../SPEC.md#基盤のサイズ制約と既知のコスト)。

アプリは粒を直接描き、窓全面の高解像度画像や履歴画像を毎フレーム作らない。ただし GPUI 自身の描画面・中間テクスチャ、OS のすりガラスと合成は別に必要である。固定粒数やアニメーション上限だけで、リサイズ確保や高 DPI の GPU コストが一定になるとは説明できない。GPU の寸法制限と面積の確保成功も別であり、対応最大サイズは実機確認に依存する。

復元ではディスプレイ相対の外枠位置と論理コンテンツ寸法を区別し、利用可能な領域へ補正する。通常窓の復元矩形をフルスクリーンの全面寸法で上書きしない。保存の座標と復帰の扱いは [復元](../SPEC.md#復元)に従う。

## 保存と更新の失敗が止めるもの

保存対象は設定の端点であり、瞬間的な天候・DSP 位相・粒・交差割合ではない。交差中の終了で次回の環境をどちらに決めるかは [保存](../SPEC.md#保存)に従う。再起動は途中の混合の再演ではない。

| 場面・失敗 | 継続するもの | 止めるもの・保護するもの | 利用者への扱い |
|---|---|---|---|
| 通常の保存失敗 | 現在の音と通常操作 | 保存成功とは扱わない | メニュー・設定窓に失敗状態を出す |
| 読めない・破損した保存ファイル | 退避後、初期設定で起動する経路 | 破損内容を正常な設定として使わない | 退避と初期設定での起動を知らせる |
| 破損ファイルの退避失敗 | 初期設定で起動する扱い | 元ファイルを上書きせず、その回の保存を失敗にする | 失敗状態を示す |
| 未対応の新しい保存バージョン | 旧版が勝手に書き換えない保護を保つ | 未対応形式の上書き | 読み込み・保存の扱いを通常成功と混同しない。本書で別の起動方針は追加しない |
| 更新確認・ダウンロード・検証の失敗 | 通常の音と設定 | 失敗した更新を成功として進めない | 手動で開いた更新画面で示す |
| 更新前の保存失敗 | 現在の音 | その回の更新・再起動を中止する | 保存失敗を成功として通過させない |
| 更新時の置き換え失敗 | アプリバンドル外の保存データを保護する | 旧設定を破壊しない。完全な自動ロールバックは保証しない | 更新成功や全面的な復旧を断言しない |

保存は変更が落ち着いた時点で一時ファイルへ書き、置き換える。未知の値の保持、欠落時の既定値、範囲の整え方は保存 Module の Implementation に閉じる。毎フレームやマウスの移動ごとの保存にしない。

更新はユーザーが確認を求めたときだけ行う。確認・ダウンロード中は音を続け、インストール・再起動も明示的な選択に従う。更新前の保存完了を確認してからフェードアウトして終了し、再起動後は保存対象の環境と設定を復元する。更新経路と失敗の正本は [アプリ内更新](../SPEC.md#アプリ内更新)。

署名・公証・更新ファイルの検証と配信条件は [配布と更新](../SPEC.md#配布と更新)および[配布前提](../SPEC.md#配布前提)に従う。本書の構成説明は、配布準備の成立、署名済み成果物の存在、公開操作の許可を意味しない。実装後に確かめる条件は [検証条件](../SPEC.md#検証条件)を参照し、設計説明と実際の証拠を分けて扱う。
